# CampusFix — Project Case Study

CampusFix is a frontend-only campus maintenance issue-reporting app built over
three weeks for BuildLab Stage 1. It demonstrates responsive design, reusable
React/TypeScript components, MSW-based mock data integration, routing, persisted
saved state, accessibility, and automated testing.

## Problem
Students lack a convenient way to report and track campus maintenance issues.

## Solution
A responsive SPA with issue listing, search/filter/sort, detail view with
status workflow and activity history, validated report form, dashboard, and
saved issues.

## Outcome
- 21 passing automated tests.
- MSW mock API with 5 endpoints.
- 3 release tags (week-1, week-2, week-3).
- Deployable static build.
