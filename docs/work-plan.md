# CampusFix — Three-Week Work Plan

## Week 1 — Foundations
- Responsive, accessible issue-listing screen.
- Search and filtering over in-memory data.
- Validated report form with success/failure feedback.
- Mobile-first layout verification.
- README, screenshots, mentor presentation outline.

## Week 2 — Components and Data
- Reusable component library (cards, badges, inputs, states).
- MSW mock HTTP API (`GET/POST/PATCH/DELETE /api/issues`).
- Typed service layer; async data loading.
- Loading, empty, error, retry states.
- Search/filter against fetched data.
- Issue log (≥5 entries), feedback response.

## Week 3 — Quality and Delivery
- React Router routes: `/issues`, `/issues/:id`, not-found.
- Deep-linking and SPA fallback.
- Saved issues persisted to localStorage.
- Accessibility audit and fixes.
- Automated tests (≥3, currently 21).
- Final deployment and verification.
- Complete README, case study, walkthrough, reflection, declaration.

## Checkpoints
- `week-1`, `week-2`, `week-3` git tags.
