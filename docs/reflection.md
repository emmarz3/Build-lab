# CampusFix — Technical Reflection

## Progress over three weeks
Week 1 established the listing screen, search/filter, and report form. Week 2
introduced reusable components and MSW data integration. Week 3 added routing,
saved state, accessibility work, tests, and documentation.

## Remaining risks
- No real backend; data is mock.
- localStorage persistence limitations.
- No numeric accessibility score (tooling unavailable).
- Deployment not verified (no credentials).

## Future improvements
- Real backend sync and authentication.
- Photo uploads.
- CI/CD pipeline.
- Full Lighthouse audit in a CI environment.
